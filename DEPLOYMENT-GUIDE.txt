QUICK DEPLOYMENT (NEW SERVER)
═══════════════════════════════════════════════════════════════════════════════

1. Upload to new server:
   ─────────────────────────
   scp flashfender-deploy.tar.gz user@your-server:/root/

2. SSH into server and extract:
   ─────────────────────────
   ssh user@your-server
   cd /root
   tar -xzf flashfender-deploy.tar.gz
   cd flashfender-deploy

3. Run deployment script:
   ─────────────────────────
   chmod +x deploy.sh
   ./deploy.sh

4. Follow prompts:
   ─────────────────────────
   - Enter domain name
   - Enter email for SSL
   - Set tracking dashboard password

5. Done! 🎉
   ─────────────────────────
   Website: https://yourdomain.com
   Dashboard: https://yourdomain.com/tracking

MANUAL DEPLOYMENT (STEP BY STEP)
═══════════════════════════════════════════════════════════════════════════════

PREREQUISITES:
──────────────
  • Ubuntu 22.04+
  • Node.js 20+
  • Nginx
  • Certbot (for SSL)
  • Domain DNS pointing to server

STEP 1: INSTALL NODE.JS
────────────────────────
  curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
  apt install nodejs -y

STEP 2: INSTALL NGINX & SSL TOOLS
──────────────────────────────────
  apt install nginx certbot python3-certbot-nginx -y

STEP 3: UPLOAD FILES
────────────────────
  Upload the entire flashfender-deploy folder to /root/

STEP 4: INSTALL DEPENDENCIES
────────────────────────────
  cd /root/flashfender-deploy
  npm install

STEP 5: BUILD APPLICATION
─────────────────────────
  npm run build

STEP 6: CONFIGURE NGINX
───────────────────────
  cat > /etc/nginx/sites-available/yourdomain.com.conf << 'EOF'
  server {
      server_name yourdomain.com www.yourdomain.com;

      location / {
          proxy_pass http://localhost:3000;
          proxy_http_version 1.1;
          proxy_set_header Upgrade $http_upgrade;
          proxy_set_header Connection 'upgrade';
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
          proxy_cache_bypass $http_upgrade;
      }

      listen 443 ssl;
      ssl_certificate /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
      ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;
      include /etc/letsencrypt/options-ssl-nginx.conf;
      ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;
  }

  server {
      if ($host = www.yourdomain.com) {
          return 301 https://$host$request_uri;
      }
      if ($host = yourdomain.com) {
          return 301 https://$host$request_uri;
      }
      server_name yourdomain.com www.yourdomain.com;
      listen 80;
      return 404;
  }
  EOF

  ln -sf /etc/nginx/sites-available/yourdomain.com.conf /etc/nginx/sites-enabled/
  nginx -t
  systemctl reload nginx

STEP 7: GET SSL CERTIFICATE
───────────────────────────
  certbot --nginx -d yourdomain.com -d www.yourdomain.com \
      --non-interactive --agree-tos --email admin@yourdomain.com

STEP 8: CREATE SYSTEMD SERVICE
──────────────────────────────
  cat > /etc/systemd/system/flashfender.service << 'EOF'
  [Unit]
  Description=FlashFender Next.js App
  After=network.target

  [Service]
  Type=simple
  User=root
  WorkingDirectory=/root/flashfender-deploy
  ExecStart=/usr/bin/npm start
  Restart=always
  RestartSec=10
  Environment=PORT=3000
  Environment=NODE_ENV=production

  [Install]
  WantedBy=multi-user.target
  EOF

  systemctl daemon-reload
  systemctl enable flashfender
  systemctl start flashfender

STEP 9: SET TRACKING PASSWORD
──────────────────────────────
  curl -X POST http://localhost:3000/api/tracking/setup \
      -H "Content-Type: application/json" \
      -d '{"password":"yourpassword"}'

STEP 10: VERIFY
───────────────
  systemctl status flashfender
  curl -I https://yourdomain.com
  curl -I https://yourdomain.com/tracking

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

SERVICE WON'T START:
  journalctl -u flashfender -f
  → Check error messages

SSL RENEWAL:
  certbot renew --dry-run
  systemctl restart flashfender

RESET TRACKING PASSWORD:
  curl -X POST http://localhost:3000/api/tracking/setup \
      -H "Content-Type: application/json" \
      -d '{"password":"newpassword"}'

RESET ALL TRACKING DATA:
  rm -f /root/tracking-db.json
  systemctl restart flashfender

CHECK NGINX:
  nginx -t
  systemctl status nginx

VIEW ALL TRACKING CODES:
  cat /root/tracking-db.json
