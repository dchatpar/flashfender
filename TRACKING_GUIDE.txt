🔗 HOW TO CREATE TRACKING LINKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Method 1: Via Dashboard
   ─────────────────────────
   1. Login to https://flashfender.com/tracking
   2. Enter description (e.g., "Facebook Ads - Winter Sale")
   3. Click "Generate Link"
   4. Copy your tracking link

   Method 2: Via API (Terminal)
   ─────────────────────────
   curl -X POST https://flashfender.com/api/tracking/create \
     -H "Content-Type: application/json" \
     -d '{"description":"Your campaign name"}'

   Response:
   {
     "success": true,
     "code": "ABC123",
     "url": "/t/ABC123",
     "createdAt": "2026-02-05T21:34:40.001Z"
   }

📊 HOW TO VIEW STATS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Dashboard:
   ──────────────
   Login to https://flashfender.com/tracking

   API Command:
   ──────────────
   curl -X POST https://flashfender.com/api/tracking/stats \
     -H "Content-Type: application/json" \
     -d '{"password":"admin123"}'

   Response shows:
   • code       - The unique tracking code
   • clicks     - Total number of visits
   • unique     - Unique visitors (by IP)
   • lastClick  - Most recent visit time

🔄 HOW TRACKING WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. You create a tracking code → gets link: /t/ABC123
   2. Share that link in your marketing
   3. Visitor clicks → redirected to flashfender.com
   4. System records:
      ✓ Timestamp
      ✓ IP Address
      ✓ Browser/Device (User Agent)
      ✓ Where they came from (Referrer)
   5. View all data in dashboard
